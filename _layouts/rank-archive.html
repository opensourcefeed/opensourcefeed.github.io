Methodology

Data source
Page views of each distribution and desktop page on OpenSourceFeed during this {% if page.archive_kind == "year" %}calendar year{% else %}calendar month{% endif %}, from the Google Analytics Data API. Hits on old or alias URLs are merged into the main page.
Popularity score
Each entry's page views divided by those of the #1 entry in the same list, scaled to 100.
Rank change
Compared with the rank in {{ snap.compare_label | default: "the previous period" }}. “NEW” means the entry was not ranked then.
Frozen data
This page is a snapshot. It is not updated after the period ends; see the live ranking for current numbers.
