**Linux Mint** is a free, desktop-focused Linux distribution built on [Ubuntu](/distribution/ubuntu) LTS releases. It pairs Ubuntu's stability with a carefully designed desktop and a pre-selected set of apps, so it works well for people switching from Windows or macOS. It uses APT for packages and supports Flatpak for sandboxed apps.

Multimedia codecs and proprietary drivers are included where needed, so audio, video and most hardware work right after installation.

## Linux Mint editions

Linux Mint has three official desktop editions, all 64-bit:

- **Cinnamon:** the flagship edition, developed by the Mint team. A familiar, traditional desktop. See [Cinnamon](/desktop/cinnamon).
- **MATE:** a lighter, classic desktop that suits older or modest hardware. See [MATE](/desktop/mate).
- **Xfce:** the lightest of the three, a good fit for low-spec machines. See [Xfce](/desktop/xfce).

Older Mint releases also had a KDE edition. It is no longer part of current releases.

## Linux Mint Debian Edition (LMDE)

[LMDE](/distribution/debian) is the Debian-based version of Mint. It gets its packages directly from Debian and uses a semi-rolling model, while keeping the same Mint desktop and tools. Pick it if you prefer Debian, or want to see how Mint works without Ubuntu underneath.

## Latest release and support

The stable 22.x series is based on Ubuntu 24.04 LTS and is supported until 2029. Mint is now moving to a yearly release cycle. The next major version, Linux Mint 27 "Adrien", is in beta. See our [Linux Mint 27 beta post](/linux-mint-27-beta-release/) for what is new.

## Download Linux Mint

Get the ISO for your edition from the [official Linux Mint download page](https://www.linuxmint.com/download.php), and verify the checksum before writing it to a USB drive. To see how the series has changed, browse the release posts below.
