Methodology

Data source
Page views of each distribution and desktop page on OpenSourceFeed, from the Google Analytics Data API. Hits on old or alias URLs are merged into the main page.
Popularity score
Each entry's page views divided by those of the #1 entry in the same list, scaled to 100.
Rank change
The current rank compared with the rank in the preceding period of the same length, for example the last 30 days against the 30 days before them. “NEW” means the entry was not ranked in the preceding period.
12-month trend
Each entry's rank in every complete calendar month of the last year, then its current 30-day rank. Monthly and yearly rankings are frozen in the archive and never change afterwards.
Biggest movers
The largest rank changes among entries currently in the top 50.
Limitations
The ranking reflects reader interest on this site only. It does not measure install base, quality or efficiency, and it is not real-time.
