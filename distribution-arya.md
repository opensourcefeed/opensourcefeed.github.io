**Arya Linux** (also written **AryaLinux**) was a source-based GNU/Linux distribution and a collection of build tools and scripts for building your own Linux system from scratch. The scripts were composed from the instructions in the Linux From Scratch (LFS) and Beyond Linux From Scratch (BLFS) books, which automated much of the manual work those books require.

The project has been **discontinued**. Development stopped after the 2.x series, and the former official domain, aryalinux.org, no longer belongs to the project. It now hosts unrelated content. Existing installations get no security updates, so Arya Linux should not be used on production or internet-facing systems.

## What Arya Linux offered

* **Build-it-yourself approach:** users could build a complete system from source with the project's scripts, or install a pre-built live image.
* **Multiple desktop editions:** GNOME, MATE and Xfce, for 64-bit (x86_64) hardware only.
* **Ready-to-use software:** besides each desktop's default applications, releases shipped an office suite, a web browser and common network utilities.
* **alps package manager:** additional software was built and installed from source through *alps*, which used BLFS-based build scripts.

## Alternatives

If you are interested in building a Linux system from source, the [Linux From Scratch](https://www.linuxfromscratch.org/) project is still actively maintained. Source-based distributions such as Gentoo also offer a similar level of control, with ongoing maintenance and security support.
